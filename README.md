# Forestery

Site web de révision regroupant des **résumés de modules** et des **examens précédents**.

🔗 **Site en ligne :** https://nilufergit.github.io/forestery/

## Contenu

- **Résumés de modules** : synthèses de cours claires et organisées par module
- **Examens précédents** : sujets d'examens des années passées, pour s'entraîner
- **Quiz** : questions pour tester ses connaissances
- **Contact** : pour envoyer une remarque, une correction ou un document

## Structure du projet

```
index.html     Page d'accueil
notes.html     Résumés de modules
quizz.html     Quiz
contact.html   Page de contact
```

## Utilisation

Ouvrir le lien du site dans un navigateur. Aucune installation n'est nécessaire.

## Contribuer

Pour proposer un résumé, un examen ou signaler une erreur, passer par la page **Contact** du site.

## Remarque

Ce site est destiné à un usage pédagogique. Les documents sont partagés pour aider à la révision et ne remplacent pas les cours officiels.
